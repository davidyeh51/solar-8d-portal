## 🧭 步驟 1：UNSW-Solar 方法深度診斷案場數據

當案場數據放置於工作資料夾時，依據 UNSW 規範執行診斷：

### 1.1 資料預處理與基準建立
- **真實容量校核**：比對竣工串接圖，以實際 DC kWp 作為各變流器計算基準，排除 SCADA 登錄誤差。
- **等價發電時數 (Equivalent Hours, Ey)**：
  $$\text{Ey}_i = \frac{\text{kWh}_i}{\text{kWp}_i}$$
- **標竿鎖定與同儕中位數**：
  找出表現最優異的標竿台（如 INV-10）及全場中位數機台（Median Peer）。

### 1.2 P2P (Performance-to-Peers) 同儕比對
- 計算各台相對標竿機台之比值：
  $$\text{Ratio}_i = \frac{\text{Ey}_i}{\text{Ey}_{\text{benchmark}}}$$
- **異常門檻**：
  - $\text{Ratio} \ge 0.90$：正常同儕
  - $0.80 \le \text{Ratio} < 0.90$：P2 效能落後（積塵、局部輕度遮蔽）
  - $\text{Ratio} < 0.80$：P1 嚴重異常（組串斷路、嚴重故障、火載隱患）

### 1.3 AC 側與 DC 側故障特徵提取
- **MPPT 電流電壓相位差異分析**：
  - 若開路/工作電壓 $V_{mp}$ 正常，但電流 $I_{mp}$ 顯著下降（如 3 併變 2 併，電流剛好降為 2/3 ≈ 65%）：**確診為組串斷路／熔絲熔斷 (String Open-circuit / Blown Fuse)**。
  - 若晴空日功率在額定功率處呈現水平平頭：**逆變器截割 (Inverter Clipping)**。
  - 若固定時段比值規律性下凹：**固定物/女兒牆/管線遮蔽 (Recurring Shading)**。
  - 若全天發電量整體偏低但曲線平滑：**油污、積塵或組件透光率下降**。

## 📝 步驟 2：8D 架構撰寫報告並直接發布在 GitHub 網頁

將 UNSW 診斷結果轉化為顧問級 8D 異常診斷決策平台，並發布上線：

### 2.1 8D 章節規範 (Strict 8D Mapping)
1. **Cover 封面**：案號代碼、廠址坐標、裝置容量、資料期間、分析引擎 (UNSW-Solar)、核心結論一句話 (The Lede)、最該帶走的一句話 (Takeaway)。
2. **摘要 (Executive Summary)**：4 大核心 KPI 卡片（標竿比值、前三大落後損失、全場年化短少 kWh、年化營收損失 NT$ 萬元）與 P1~P4 優先處理矩陣。
3. **D0 立案反應 ＆ D1 跨職能分工**：
   - UNSW 演算法自動偵測立案路徑。
   - 現場電氣安全評估：判定是否需急停機；針對斷路警示 670V~1000V 高壓直流電弧 (DC Arc Flash) 起火風險。
   - RACI 四方權責分工表（資料分析 A、現場執行 R、監控系統 C、業主窗口 I）。
4. **D2 問題描述 (量化 5W2H)**：
   - 5W2H 結構量化。
   - 逐台發電量、等價時數、短少度數與年化損益排名表格與視覺圖表。
5. **D3 暫時圍堵措施**：
   - 止血行動清冊（如 48 小時內 FLIR 熱像儀直流箱掃描、LOTO 斷電鉗表測量）。
6. **D4 根本原因分析 (Root Cause)**：
   - UNSW 遙測對比實證圖（如 INV-10 vs INV-11 MPPT 電流電壓曲線對比）。
   - 「排除之假設清單表格」：明確以數據排除削峰、電網過壓、PID/老化、感測器倍率失真等假說。
7. **D5 永久對策選定 ＆ D6 執行與效果驗證**：
   - 方案比選矩陣（技術工法、投入成本、產出效益、回本期）。
   - 效果驗證門檻：設定比值連續恢復至 $\ge 0.90 \sim 0.95$ 為結案指標。
8. **D7 防止再發 ＆ D8 結案增益**：
   - 維運 SOP 修訂（季度納入 MPPT 電流均衡度點檢）。
   - SCADA 自動告警規則：同儕比值偏離中位數 15% 連續 3 天自動派工。
   - 財務模型總結：20 年 DCF 累計增益 (NT$ 萬元) 與專案 IRR 推升百分比。
9. **附錄與作業安全警語**：
   - 逐日原始數據對帳檢視器（支援搜尋與 CSV 匯出）。
   - 1000V DC 帶電防弧、高空防墜與 LOTO 上鎖掛牌工安警語。

### 2.2 直接發布在 GitHub 網頁 (GitHub Pages Deployment)
在終端機一鍵執行：
```bash
# 1. 建立獨立專案儲存庫並推播
gh repo create davidyeh51/{plant-id}-diagnostic --public --source=. --remote=origin --push

# 2. 開啟 GitHub Pages 託管
gh api --method POST repos/davidyeh51/{plant-id}-diagnostic/pages -f "source[branch]=main" -f "source[path]=/"

# 3. 取得公開網址並驗證
https://davidyeh51.github.io/{plant-id}-diagnostic/
```

### 2.3 登錄至 8D 管理門戶 (solar-8d-portal)
將產出的報告案號、電廠名、短少度數、年化損失與公開網址登錄至 `https://davidyeh51.github.io/solar-8d-portal/`，確保全台維運資產集中列管。
