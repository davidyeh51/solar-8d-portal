# 太陽光電電廠 8D 決策平台 HTML 視覺與互動架構規範 (Architecture Guideline)

本文件定義統一的 HTML 視覺格式、CSS 設計語言、組件拓撲與 JavaScript 互動引擎規範。確保未來無論任何案場、任何逆變器廠牌，產出之決策平台在排版、配色、互動樣態與操作體驗上**100% 保持高度嚴格一致**。

## 3. 雙核證據溯源與互動模態 (Evidence & Modals)

### 3.1 燈箱相片證據系統 (Photo Lightbox Modal)
* 點擊任意施工圖（EV-02）、現場實拍（EV-03/04）或 SCADA 截圖（EV-01），均可開啟高解析度放大燈箱。
* 顯示 EV 編號標籤、相片分類、拍攝時間戳記、對應 D 步驟與詳細工程說明。

### 3.2 原始數據對帳檢視器 (Raw Data Provenance Modal)
* 右上角提供「📊 原始數據對帳」，開啟包含 90 天逐日發電度數與同儕離散比率的對帳清冊。
* 支援**即時關鍵字搜尋過濾**、**一鍵複製數據 (貼入 Excel)** 及 **一鍵匯出 CSV 檔 (含 UTF-8 BOM)**。

### 3.3 模式動態切換 (Mode Switcher)
* 頂部配置「模式：內部維運版 ⇄ 切換為業主版」即時切換按鈕。
* 點擊後無須重整頁面，即時更新網頁標題、徽章色彩與文字標註，滿足工程與投資人兩種報告需求。
